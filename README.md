# 午夜来信 MIDNIGHT ORACLE

> 有些问题，值得静下来听听自己的答案。

一个离线「塔罗 + 答案之书」工具。牌面给你意象，一句话替你开口，剩下的由你自己补完。
工具**不收集问题、不预测未来**：它只抽出一张牌，翻到那一页，读出一句可以自由解读的提示语。

## 2. 运行方式

### 从零构建（干净克隆后）

```bash
# 1) 配乐不入版本库，需自己提供：把 music.mp3 放进项目根目录后裁出前一分钟
ffmpeg -y -i music.mp3 -t 60 -af "afade=t=in:st=0:d=1.2,afade=t=out:st=58.4:d=1.6" \
  -c:a libmp3lame -b:a 64k -ar 48000 -ac 2 app/assets/audio/music.mp3

# 2) 生成字体子集（需要 .asset-cache/fonts 下的原始字体）
python scripts/build-fonts.py

# 3) 打包
python scripts/build-zip.py

# 4) 自审
node scripts/audit.js

# 5) 源码终检（大小写敏感的引用核对，适用于 Android / Linux 容器）
python scripts/check-source.py
```

> 配乐缺失时 `build-zip.py` 会给出提示；应用也能正常运行，只是没有背景音乐。
> `dist/` 与 `screenshots/` 不入库，交付 zip 请以 GitHub Release 附件形式发布。

### 小红书小工具

1. 上传 `dist/midnight-oracle-1.0.0.zip`。
2. 在创服平台模拟器完成流程验证。

当前环境未登录创服平台，也未连接真机；相关项目仍需人工验收。

## 3. 核心闭环

进入占卜室 → **静心一分钟** → 洗牌 → 选牌 → 翻开书页 →
一句提示语 + 这张牌的释义 → 再翻一页 / 保存这一页 / 再占卜一次。

状态机：

```text
home → ritual → shuffling → card_reveal → result
```

**抽牌即翻书**：22 张大阿尔卡那 × 正逆位 = 44 页。抽到哪张牌，就翻开哪一页；
牌面是该页的插图，提示语是该页唯一的一句话。再往后翻是「夹页」，
取自这张牌的其他说法与通用句，但**牌不会变**。

**静心页**取代了原来的问题表单：没有输入框、没有主题与情绪的勾选。
用户只需要闭上眼睛呼吸三次、在心里默念问题，然后点「我准备好了」。
这既符合答案之书的原理（心中默念，不必写下，写下来它就变成一件待办），
也让整个流程没有任何填写负担。

## 4. 答案之书内容层

| 内容 | 规模 | 说明 |
| --- | --- | --- |
| 提示语 | **264 句** | 22 牌 × 正逆位 × 6 种此刻状态（犹豫 / 不甘 / 疲惫 / 期待 / 卡住 / 看清） |
| 牌面释义 | 44 段 | 每张牌正逆位各一段释义 + 象征元素 + 4 个关键词（来自牌库原有数据） |
| 通用句 | 48 句 | 夹页使用，不属于任何一张牌 |

写法的三条硬规则：

1. **不回答问题**。句子不给结论、不给时间表、不给建议。
2. **只说「人」，不说「事」**。不出现关系、工作、金钱等任何具体话题，
   所以「他会不会回来」「我该不该离职」「我最近很累」都能套上同一句。
   自审脚本会检查每句都不含具体话题词，且长度在 10–26 字。
3. **模糊但可否认**。短句、指向此刻的状态，读起来像在说你，也允许被否认。

**主句**从这张牌这一面的六句里稳定随机落一句；其余五句与全部通用句、
以及牌面自带的那一句，混进**夹页**候选——「再翻一页」能翻出同一张牌的另一种说法，
但**牌不会变**。

**不设主题**。问题在用户心里，工具不替他定方向：静心页只让他呼吸与默念，
书页上也不出现任何主题标签。

### 4.1 牌面释义（替代原来的「三个自问」）

书页下半部分改为**这张牌本身的介绍**，读起来像一段牌面说明，而不是让用户自我提问：

- 标题「关于这张牌」
- 释义正文：该牌在当前朝向上的含义（牌库原有 `summary`）
- 象征：该牌的画面元素（`symbol`，如「辉煌的日轮悬于围墙之上，下方是向日葵与一匹白马」）
- 四个关键词标签（如 明朗 / 活力 / 被看见 / 确认）

原先那批「三个自问」文案（132 句）已退出运行包，内容保留在
`archive/08-questions-archive.js`，需要时可取用。

## 5. 牌库与视觉

- 22 张大阿尔卡那使用 1909 Rider-Waite-Smith 公共领域本地图片。
- 力量编号为 VIII，正义编号为 XI。
- 牌背为原创 180° 对称 SVG：月轮星徽、十二芒、四瓣玫瑰、连续波纹与双层书脊边框。
- 书页为深蓝黑档案纸：装订线、页眉页码、折角标记，翻页使用 3D rotateY。
- 页面不加载外部字体、远程图片或 CDN 资源。

### 5.2 资源预热：弱网下也不掉链子

部署给真实用户时，网络速度不可控，所以**动画开始前必须把资源准备好**：

| 资源 | 预热时机 | 效果 |
| --- | --- | --- |
| 字体（思源宋体 / Cinzel） | 启动时 `document.fonts.load()` | 首屏不再出现「回退字体 → 跳变」 |
| 牌面图 | **洗牌一开始**就随机定下这一轮的牌并后台 `Image` 预加载 | 洗牌动画 1.4 秒足够下载并解码完，翻面时不会翻出空框 |
| 分享卡用图 | 打包为 data URI，随 JS 一起到达 | 零网络请求，画布直接可画 |
| 配乐 | 用户点开声音时才加载（`preload="none"`） | 不为不听的用户浪费流量 |

牌面图的降级链（任何一环失败都不会掉风格）：

```
360px 文件 → 包内 data URI 副本（220×367，同一张 RWS 牌面）→ 代码生成的 SVG 徽记
```

揭示动画在翻面前最多再等 600ms（正常情况图片早已就绪，这个等待只是兜底）。

### 5.1 内置字体（两款，均为 SIL OFL 1.1，可商用可内嵌）

| 字体 | 用途 | 体积 |
| --- | --- | --- |
| **思源宋体 Noto Serif SC** | 全部中文：界面、标题、牌名、那一句提示语与自问 | 354 KB |
| **Cinzel** | 英文眉题、字标、页码（罗马碑刻大写） | 21 KB |

- 字体栈统一为 `--latin`：`"Cinzel", "Noto Serif SC", "Trajan Pro", Georgia, serif`
  —— 拉丁字符走 Cinzel，中文走思源宋体。**「今晚这一页」整页与页眉
  「MIDNIGHT ORACLE · 答案之书」使用同一套字体**。
- 全部**子集化**为 WOFF2：只保留应用真正用到的字（1059 字 / 拉丁 99 字符），
  由 `scripts/build-fonts.py` 可复现生成。
- 授权信息随包分发：`app/assets/fonts/licenses.json`。
- 分享卡用 canvas 绘制，绘制前会等待字体就位（最多 1.5 秒，超时回退系统字体），
  避免海报上出现回退字体。
- 曾试过用霞鹜文楷渲染那一句提示语，实测不如统一宋体，已移除（省下 266 KB）。
- 牌面按真机展示尺寸重编码：页面用 288×480（最大展示 174 CSS px），
  分享卡画布副本 220×367；原始 720×1200 素材保留在 `.asset-cache/` 供重新生成。
  页面图加载失败时自动改用包内 data URI 副本（仍是同一张牌面），最后才退到代码徽记。
- 牌面加载带换档兜底：主路径 404 时自动改用另一档尺寸目录，最后才退回代码徽记，
  避免「客户端缓存了旧脚本、包内已换素材」时白屏。

## 5.1 手势洗牌与音效

**手势洗牌**（抽牌页）

- 按住牌堆左右拖动：牌堆跟手移动并逐渐切成两包，拖动越快倾斜越大。
- 松手后牌按 **riffle 交错模型** 落下、收拢、展开；手劲越大交错越随机，
  每次洗牌的顺序都不重复上一轮。
- 「洗牌」按钮保留为等效路径：点按即完成一次自动 riffle 洗牌，
  键盘与无障碍用户不受影响。
- 降低动效偏好（`prefers-reduced-motion`）时自动只保留按钮路径。

**手势抽牌**

- 牌阵就绪后，按住任意一张牌可直接把它**拖出来**：牌跟随手指移动并抬起，
  松手处原地翻开，越过阈值即抽定。
- 位移很小的轻点仍走原来的点击路径，行为不变。
- 拖出后浏览器补发的 click 会被抑制，不会重复抽牌。
- 牌阵就绪时牌面禁用页面滚动手势（`touch-action: none`），拖拽不会误触发滑动。

**音效**（全部实时合成，包内无音频文件）

| 声音 | 合成方式 |
| --- | --- |
| 洗牌沙沙 | 白噪声缓冲 + 带通滤波，响度与音高随拖动速度实时调制 |
| 牌落桌 | 短噪声爆音 + 低频正弦闷响，逐张落下时触发 |
| 翻牌 | 高频噪声扫频，模拟牌面摩擦 |
| 揭示铃音 | 三个衰减正弦叠加，呼应「午夜来信」的古典调性 |

- 首次用户手势时才创建 AudioContext（符合移动端自动播放策略）。
- 右上角提供静音开关，状态写入 `aria-pressed`。
- 不支持 Web Audio 或被系统策略拒绝时静默降级，功能不受影响。

## 6. 声音：配乐 + 音效

**全局声音按钮**（右下角悬浮，所有页面可用，`aria-pressed` 标注状态，默认静音）

| 声音 | 做法 |
| --- | --- |
| 环境配乐 | **包内音频文件** `assets/audio/music.mp3`：取用户提供的音乐**前一分钟**，重编码为 64 kbps 立体声（480 KB），首尾带淡入淡出，网页内 `loop` 循环播放，音量 0.35。**默认自动开启** |
| 揭示钟音 | 翻牌瞬间一记清亮铃音（880Hz + 泛音，Web Audio 合成），叠在配乐之上 |
| 洗牌沙沙 | 循环白噪声 + 带通滤波，响度与音高随拖动速度实时调制 |
| 落桌 / 翻牌 | 短噪声爆音 + 低频正弦 |

- 配乐为包内 mp3（用户提供的音乐，仅保留前一分钟）；其余音效全部实时合成。
- 音频上下文只在用户手势后创建/恢复（符合移动端自动播放策略）。
- 配乐默认自动开启：先尝试直接播放；若被浏览器的自动播放策略拦下，
  则挂一次性手势监听，用户第一次点击时自动开始（按钮状态同步变为「开」）。
  用户手动关掉后不再自动开启。
- 配乐音量压得很低（主增益 0.13，2.8 秒淡入 / 1.2 秒淡出）。
- 原始音乐文件保留在项目根目录 `music.mp3`（4.33 MB，2 分 22 秒）；
  包内只放裁剪重编码后的 60 秒版本，重新裁剪可用：
  `ffmpeg -y -i music.mp3 -t 60 -af "afade=t=in:st=0:d=1.2,afade=t=out:st=58.4:d=1.6" -c:a libmp3lame -b:a 64k -ar 48000 -ac 2 app/assets/audio/music.mp3`

## 8. 隐私

- 工具**不收集问题**：状态页没有输入框，页面不存在 `textarea` 与问题字段。
- 不写入本地存储。
- 分享图片与发布正文只包含提示语、牌名与自问，不含任何用户输入。

## 9. 兼容与交付约束

- `index.html` 位于 ZIP 根目录，所有脚本外置，ZIP 条目名一律正斜杠。
- JavaScript 目标为 ES2017 / Chrome 61。
- 不使用内联脚本、行内事件、iframe、eval、XMLHttpRequest、WASM 或 Worker。
- 不引入任何音频资源文件：音效由 Web Audio 实时合成。
- 不调用平台 AI（`window.xhs.AI` 相关代码已全部移除），无需 appId 加白。
- CSS 不使用 `aspect-ratio`、`clamp()`、逻辑属性、`:has()` 或动态视口单位。
- 安全区均提供 Chrome 61 可解析的静态回退。
- 洗牌与翻页均有计时器兜底。
- 交付包只包含一个 HTML 入口与允许的文件类型。
